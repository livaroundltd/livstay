# LivStay

An open protocol for personal agents to find, ask about and book independent homes.

LivStay is an extension of the [Personal Agent Protocol](https://personalagentprotocol.org) (Poppy) draft 0.2, named `livstay.org/stays`. Poppy covers discovery, sign-in, sessions, conversations and confirm-before-act. LivStay adds what is specific to stays: the home, its facts, availability, binding quotes, terms, protection, enquiries to the host, and bookings the traveller approves.

**Status: draft 0.2.** Until 1.0, a revision can break compatibility with earlier drafts; both sides say which revision they speak (`LivStay-Revision`).

## Levels

| Level | Name | An agent can |
| --- | --- | --- |
| 0 | Listed | Read homes, facts, terms and protection |
| 1 | Priced | Read availability and get binding quotes |
| 2 | Reachable | Ask the host questions |
| 3 | Bookable | Book, change and cancel |

## Repository layout

| Path | What |
| --- | --- |
| `spec/` | The normative specification, one file per draft |
| `schemas/` | JSON Schema 2020-12 for every object (normative). Generated by `tools/make_schema.py` |
| `openapi/` | OpenAPI 3.1 for every endpoint (normative for paths and status codes). Generated by `tools/make_openapi.py` |
| `fixtures/0.2/` | Valid and invalid example objects, signed with a published **test** key |
| `tools/validate.py` | Checks fixtures, or one object of yours, against schemas, reconciliation and signatures |
| `tools/conformance.py` | Level 0 and 1 checks against a live host platform |
| `tools/mock_host.py` | A one-file Level 1 host platform for local testing |
| `tools/livstay_jws.py` | Canonical JSON, ES256 signing and verification |
| `site/` | Sources for livstay.org: the home page, styles and docs content |
| `tools/build_site.py` | Renders `site/` and `spec/` into `docs/` |
| `docs/` | The built site, served by GitHub Pages from `main` → `/docs`. Generated: edit `site/` or `spec/` and rebuild, never edit `docs/` by hand |
| `.github/workflows/pages.yml` | Checks generated files, fixtures and the conformance runner |

Build locally:

```sh
pip install markdown==3.10.3
python3 tools/build_site.py   # writes docs/; commit it with your change
python3 -m http.server -d docs 8000
```

## Check an implementation

```sh
pip install jsonschema cryptography
python3 tools/conformance.py https://your-host-platform.example   # Levels 0 and 1
python3 tools/validate.py Quote quote.json --keys keys.json        # one object
```

Try it locally first: `python3 tools/mock_host.py 8765` in one terminal, `python3 tools/conformance.py http://localhost:8765` in another.
